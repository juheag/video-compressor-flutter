# Videocomprime

Herramienta móvil para compresión, optimización y conversión local de archivos de video en iOS.

## Características
* Procesamiento y transcodificación técnica 100% local en el dispositivo.
* Reducción de peso sin comprometer la privacidad del usuario.
* Compatibilidad con múltiples formatos multimedia.
* Suscripciones y compras integradas mediante Apple StoreKit y RevenueCat.
